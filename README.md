# 单词小英雄 · 小学英语单词记忆游戏

一个给小学生用的英语单词记忆游戏：把课本词汇做成六种小游戏，按「熟练度」自动出题，越不熟的词出现得越频繁，形成**练 → 测 → 找漏 → 再练**的循环。

纯前端实现，**双击 `index.html` 就能玩**，不需要安装、不需要联网、不需要构建工具。

## 六种游戏

| 游戏 | 玩法 | 考察点 |
| --- | --- | --- |
| 🔍 看词选义 | 给出英文单词，四选一选中文意思 | 词义辨认 |
| 🎧 听音辨词 | 自动朗读英文，从四个单词中选出听到的那个（可重听、可看中文提示） | 听音辨形 |
| ✏️ 拼写大挑战 | 给中文提示和空格，用字母块把单词拼出来（支持键盘直接输入） | 拼写记忆 |
| 🍬 消消乐配对 | 英文卡与中文卡混排，点两张配对成功即消除，清空整盘过关 | 形义联结 |
| 🔨 打地鼠抢答 | 9 秒内从冒出的小地鼠中敲中写着正确答案的那只 | 快速反应 |
| 🃏 记忆翻牌 | 翻牌配对中英文，全部配对完成即过关 | 短时记忆 |

一局 8 题（配对类为 6–8 对），通关后结算页会出现「下一关」，可以连续闯关；首页还会挑出你历史成绩最弱的那一关做推荐，避免只挑喜欢或擅长的玩。

## 循环练习机制

每个词条独立维护一条熟练度记录，存放在浏览器本地：

| 字段 | 含义 |
| --- | --- |
| `stars` | 熟练度星级 0–5 |
| `correct` / `wrong` | 累计答对 / 答错次数 |
| `streak` | 当前连对次数 |
| `lastSeen` | 最近练习时间 |
| `nextReview` | 下次该复习的时间 |

**升降星规则**：答对 `stars + 1`（上限 5），答错 `stars - 1`（下限 0），同时清空连对。

**间隔复习**：按星级给出复习间隔 `[0, 1, 2, 4, 7, 15]` 天，星级越高，下次复习时间越晚；到期未练的词会额外加权。

**加权抽题**（Efraimidis–Spirakis 加权不放回抽样）：

```
权重 = 1 + (5 - stars) × 1.6          // 星级越低越重
     + min(6, wrong × 1.2) × (stars ≤ 2 ? 1 : 0.4)   // 错过的词加重
     + 3（若已到复习时间）
     + 2（若从未练过）
     × 0.55（若已连对 3 次以上，暂时降温）
```

结果是：**新词一定会被照顾到，错词反复出现，熟词逐渐减少打扰**。同一局内不会重复抽到同一个词。

## 词库

共 **117 条**，全部来自课本与随堂复习卷（`单词库/` 目录下 6 张原始照片，一并保存在仓库中备查）：

| 单元 | 主题 | 条目 |
| --- | --- | --- |
| Unit 1 | 我的校园 | 28 |
| Unit 2 | 我的同学 | 42 |
| Unit 3 | 可爱的动物 | 34 |
| Unit 4 | 快乐的聚会 | 13 |

按类型分：单词 82 条、词组 29 条、句子 / 交际用语 6 条。

来源覆盖：

- 课本 *Words to use* 的 Unit 1–4 词表
- Reading time 1《My school》重点词与词组
- Reading time 2《My classmates》重点词与词组
- Reading time 3《Animals and their homes》重点词与词组
- 三张卷子里出现的 14 类句型（be good at / 频度副词 / help 的两种说法 / Shall we… / 现在进行时 等），显示在家长报告页的「语法小贴士」中

每条词条包含：英文、词性、教材原释义、例句、例句翻译、记忆小提示。

> 中文释义严格依照教材原文，未改写、未增补义项。例如 `duck` 在本单元是 **v. 躲闪；躲避**，`lives` 是 **n. 生命（life 的复数）**。

## 快速开始

**方式一（推荐）**：双击 `index.html`，用 Chrome 或 Edge 打开即可。

**方式二**：如果浏览器对本地文件限制较严，可以起一个静态服务再访问：

```bash
# 任选一种，然后在浏览器打开 http://localhost:8080
python -m http.server 8080
npx serve .
```

首次打开时建议先按一下页面上的喇叭按钮，让浏览器允许播放声音（浏览器要求用户先有交互才能出声）。

## 家长端

入口在右上角「家长报告」：

- **掌握度总览**：已掌握（≥ 4 星）/ 学习中 / 未学习 三段占比
- **单元进度**：四个单元各掌握多少，还差几个
- **错词本**：按「错得多 + 星级低」排序，含错误次数、当前星级、最近练习时间，可单词专练或一键专练全部错词
- **最近 7 天**：每天答题数与学习时长（只在页面前台且游戏进行中计时，后台挂机不计）
- **语法小贴士**：14 条本单元重点句型的规则与例句

数据全部存在本机浏览器（`localStorage`，键名 `ewg.data.v1`），不上传任何服务器。换浏览器或清理浏览器数据会丢失进度，设置页可手动清空。

## 项目结构

```
index.html              页面骨架（只含容器和脚本清单）
css/
  theme.css             设计变量、顶栏、按钮、卡片、星级等基础样式
  app.css               布局、页面通用组件、弹层、提示条
  games.css             六个游戏各自的界面样式
js/
  main.js               启动、路由挂载、顶栏渲染
  core/
    router.js           hash 路由
    store.js            本地存档（localStorage + 内存降级）
    progress.js         熟练度引擎：星级、间隔复习、加权抽题、统计
    audio.js            系统语音合成 + WebAudio 音效
    ui.js               弹层、撒花、抖动、星级、朗读按钮等公共 UI
    kit.js              洗牌、干扰项生成、键盘绑定、计时器集合
  data/
    words.js            词库、单元主题、语法小贴士（唯一数据源）
  games/
    quiz-meaning.js     看词选义
    listening.js        听音辨词
    spelling.js         拼写大挑战
    match.js            消消乐配对
    whack.js            打地鼠抢答
    memory.js           记忆翻牌
  pages/
    home.js             首页
    wordbook.js         单词本
    play.js             关卡外壳（出题、计分、反馈、结算）
    report.js           家长报告
    settings.js         设置
单词库/                  6 张课本与复习卷原始照片
```

六个游戏统一实现同一套接口（`create({ items, onAnswer, finish, ... })`），所以新增一种玩法只要在 `js/games/` 里加一个文件、在 `index.html` 里加一行 `<script>` 即可，关卡循环会自动把它接进轮换顺序。

## 技术说明

- **零依赖**：没有 npm 包、没有 CDN、没有构建步骤，全部是原生 HTML/CSS/JavaScript。
- **可离线**：不请求任何网络资源；发音用系统语音合成（`speechSynthesis`），音效用 WebAudio 实时合成，所以没有任何音频文件。
- **为什么不用 ES Module**：页面是 `file://` 直接打开的，`import` 会被 CORS 拦截，本地 JSON 也读不了。因此脚本按依赖顺序用普通 `<script src>` 加载，模块统一挂在 `window.EWG` 命名空间下，词库写成 `.js` 常量。
- **降级策略**：
  - 系统没有英文语音时，「听音辨词」自动切到「看中文选英文」模式，并给出提示，不会卡住；
  - `localStorage` 被禁用时切到内存存储，设置页会提示「成绩只在本次打开有效」；
  - 关卡初始化异常时显示友好提示，而不是白屏。
- **动效**：全部基于 CSS `transform` / `opacity`，粒子数量有上限，用完即回收。

## 扩充词库

编辑 `js/data/words.js` 中对应单元的 `RAW` 数组，每行是一条词条：

```js
// [英文, 中文, 词性, 例句, 例句翻译, 记忆提示(可省), 来源标记(可省)]
["classroom", "教室", "n.", "Our classroom is big and bright.", "我们的教室又大又明亮。", "class（上课）+ room（房间）"]
```

字段说明：

- `id` 由 `u<单元号>-<英文 slug>` 自动生成，重复时自动追加序号，无需手写
- 词性用 `n. / v. / adj. / adv. / phr. / sent.`
- 含空格或带句号的条目会被自动识别为词组 / 句子
- 拼写关只抽**纯字母、长度 3–11** 的单词（词组与句子会自动跳过，不进入拼写题）

改完保存，刷新页面即可生效，历史熟练度按 `id` 保留。

## 已知限制

- 面向**电脑浏览器**设计（1280×720 及以上体验最佳），平板可用、手机未做专门适配。
- 发音质量取决于系统装的语音包；Windows 建议在「设置 → 时间和语言 → 语音」里安装一个英文语音。
- 熟练度数据只在本机、本浏览器内，不支持多设备同步。
- 本项目为家庭学习用途，未附加开源许可证。
